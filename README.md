# Eldermoor [RPG] 1.7.7

Minecraft 1.20.1, Forge 47.4.28.

## First time
1. Get the starter pack (`Eldermoor-RPG-1.7.7-client.zip`) from whoever runs the server and import it in CurseForge
   (Create Custom Profile > Import).
2. Play. That's it.

Already playing a copy from Google Drive? Download
[Update Eldermoor.bat](files/Update%20Eldermoor.bat) and the `eldermoor-update` folder
([update.ps1](files/eldermoor-update/update.ps1), [source.json](files/eldermoor-update/source.json)) into your
profile folder (CurseForge: right-click the profile > Open Folder), then follow "Updating".

## Updating
1. Close the game.
2. In the profile folder, double-click **Update Eldermoor.bat**.
3. It downloads only what changed. Your worlds, settings, keybinds, servers list and any mods you added yourself stay as
   they are; the performance preset you chose is applied again. Anything of yours it had to replace is kept in
   `eldermoor-update\backup`.

If the updater says the release needs a different Forge: right-click the profile > Profile Options > Modloader.
`Update Eldermoor.bat check` only shows what an update would download.
